## 0. 분석 개요
- 분석 목적: 새로운 전투 시스템 구상을 위한 장단점 도출
- 분석 범위: 명조의 공명회로, 협주·변주·반주, 패링·공진 수치, 에코와 그 연결
- 플레이 환경·버전: windows 3.6 — 기존 기재 유지
- 기본 공격·이동·회피의 공통 설명: <mention-page url="https://app.notion.com/p/3c6ec13062558195be0dc066639a1ec8"/>
- 작성 근거: 작성자의 플레이 경험. 인게임 설명

</callout>

### 3.1. 충전과 교체
타격·스킬별 협주 에너지 획득 → 협주 충전 → 캐릭터 교체
<table header-row="true">
<tr>
<td>교체 조건</td>
<td>발동 효과</td>
</tr>
<tr>
<td>협주 미충전</td>
<td>캐릭터만 교체 / 변주·반주 미발동</td>
</tr>
<tr>
<td>협주 충전 완료</td>
<td>퇴장 캐릭터의 반주 + 등장 캐릭터의 변주</td>
</tr>
</table>
<callout icon="📝" color="gray_bg">
	협주는 교체 자체의 허가 조건이 아니다. ‘타격만 해도 충전’은 플레이 설명이며, 행동별 획득 조건·양은 스킬 설명으로 확인한다. 스킬의 협주 추가 획득을 서포터·서브 딜러만의 전용 규칙으로 단정하지 않는다.
</callout>

</callout>
## 4. 패링·공진 수치 — 적 대응
### 4.1. 표시와 성공 보상
패링 가능 공격 → 금색 원형 표시로 대응 시점 안내 → 공격 타이밍 일치 → 패링 → 공진 수치 감소 
→ 공진 수치 소진 시 **무력화**
### 4.2. 패링과 회피의 선택
<table header-row="true">
<tr>
<td>대응</td>
<td>성공 시</td>
<td>비용·위험</td>
</tr>
<tr>
<td>패링</td>
<td>공격 대응과 공진 수치 감소</td>
<td>실패 시 피격·경직 → 사이클 지연</td>
</tr>
<tr>
<td>회피</td>
<td>피격을 피하고 전투 지속</td>
<td>스태미나 소모 / 실패 시 피격 / 해당 패링의 공진수치 감소 이득 포기</td>
</tr>
</table>
패링 실패 → 피격·경직 → 버프 시간 경과 → 버프 안에 수행할 공격량 감소
<callout icon="📝" color="gray_bg">
	‘소울류보다 패링이 쉽다’는 작성자의 체감이다. 문서에서는 표시가 제공하는 정보와 실제 성공 난도를 구분한다. 회피의 스태미나 소모 조건과 예외는 인게임 기준으로 확인한다.
</callout>
### 4.3. 선택이 제한되는 기믹
일반 전투: 패링 또는 회피 선택<br>작성자가 지적한 일부 즉사 패턴: 패링 요구 → 실패·재시도 부담
<callout icon="📝" color="gray_bg">
	해당 적·패턴명, 즉사 조건, 회피·거리 이탈 등 다른 생존 수단의 유무를 확인한 뒤 사례를 넣는다. 확인 전에는 모든 즉사 패턴의 공통 규칙으로 확정하지 않는다.
</callout>

</callout>
## 6. 연결 사례 — 수수 → 루실라 → 히유키
<callout icon="📝" color="gray_bg">
	시스템이 한 사이클에서 연결되는 모습을 보여주는 단일 파티 사례다. 게임 전체의 장단점을 이 파티 성능으로 대체하지 않는다. 아래 단계는 작성자 설명 기준이며 수치·스킬명·조건은 캡처로 보충한다.
</callout>

</callout>
