초반 진행을 지원하며 **기본 조작·전투 규칙과 게임 고유의 조건부 연계**를 익히게 하는 초기 캐릭터 제안입니다.

> 초기 캐릭터 분석 → 캐릭터 설계를 위한 전투 전제 → 공격·스킬 구성 → 운용과 제안 요약

## 01 초기 캐릭터 분석

### 초반 진행과 시스템 학습

기본 지급 캐릭터는 신규 유저에게 필요한 기능을 제공하고, 그 기능을 사용하며 게임의 규칙을 익히도록 돕습니다. 파티에서 대체되더라도 초반 진행과 시스템 학습을 담당하는 역할은 필요합니다.

| 사례 | 공통 학습 | 게임별 학습 요소 |

| 엠버 · 원신 | 일반 공격·조준 사격·스킬 | 불·풀의 연소 반응 / 횃불 점화 등 탐험에서의 원소 활용 |
| 엔비 · 젠레스 존 제로 | 일반 공격·특수 스킬 | 그로기 축적 → 공격 기회 확보 / 강한 타격 후 콤보 스킬 연결 |

**도출한 기준: 초기 캐릭터는 기본 전투와 게임 고유 시스템의 학습을 함께 담당합니다.**

## 02 캐릭터 설계를 위한 전투 전제

### 차용한 전투 구조

공통 조작은 이동·공격·회피·스킬·필살기·교체입니다. 그 위에 교대 공격과 조건부 연계를 결합합니다.

| 참고 역할 | 레퍼런스 | 가져오는 요소 |
|---|---|---|
| 교대 공격 | 명조 | 협주 충전 후 교대하며 공격 연결 |
| 조건부 연계 | 엔드필드 · 가디언 테일즈 | 캐릭터별 조건 충족으로 연계 기회 생성 |
| 표시·입력 | 붕괴3rd | 강조된 초상화 입력으로 연계 실행 |

> 조건 충족 → 제한 시간 내 초상화 입력 → 교대·연계 공격

### 조건부 QTE의 설계 의도

교대하며 공격을 연결하는 경험을 유지하고, 기회 생성 방식을 게이지 충전 중심에서 캐릭터별 전투 조건 중심으로 변경합니다. 상태이상 부여·온필드 피격·스킬 적중 등 캐릭터별 트리거를 파악해 연계 기회를 능동적으로 유도하는 방향입니다.

연계 쿨타임이 준비된 상황을 전제로 합니다. 이 제안 캐릭터의 구체적인 조건은 **동료의 필살기 적중**입니다.

### QTE 입력 시간

| 비교 사례 | 연계 가능한 시간 | 의미 |
|---|---|---|
| 가디언 테일즈 | 약 2.5초 | 상태이상 중 연계 |
| 본 제안 | 4초 | QTE 입력 유예 |
| 엔드필드 | 5초 | 조건 충족 후 연계 |

진행 중인 행동을 마무리하고 교대를 판단할 시간을 두기 위해 사례 범위 내에서 **4초를 초기값**으로 설정했습니다. 입력 시간은 플레이 흐름에 맞춰 조정할 수 있습니다.

### 기본 조작과 연계 규칙

| 항목 | 규칙 |
|---|---|
| 파티 | 3인 구성 · 온필드 1인 · 자유 교대 |
| 기본 전투 | 이동·점프·일반·강·낙하 공격·스킬·회피 / 공격 → 에너지 → 필살기 |
| 쿨타임 | 전투 스킬·연계 스킬·필살기 각각 독립 |
| QTE 활성화 | 동료 발동 조건 충족 + 대기 캐릭터의 연계 쿨타임 완료 |
| 활성 중 입력 | 4초 안에 강조된 초상화 터치 또는 교대 키 → 교대와 연계 공격 |
| 미입력 | 4초 후 연계 기회 소멸 |
| 일반 교대 | 평상시 초상화 터치 → 일반 교대 |
| 속성 | 약점·내성에 따라 피해 효율 변화 · 별도 이상 피해 없음 |

## 04 개별 공격과 판정

### 일반 공격 — 4타 모션과 타격 구간

> 준비 → 1타 → 연결 → 2타 → 연결 → 3타 → 연결 → 4타 → 회복

- 양양의 일반 공격 모션 참고.
- 1~4타 모두 전방 횡베기. 각 타격에 유사한 부채꼴 범위 적용.
- 각 타격 시작 시 대상 방향으로 보정하며 짧게 전진.

### 강공격 — 홀드 전환과 전방 2회 타격

**입력 시작부터 일반공격 모션 중에도 홀드 시간을 누적합니다.** 홀드 조건을 충족하면 전환 가능한 시점에 강공격으로 이어지며 스태미나를 소모합니다.

> 일반공격 1타 → 강공격 전환 → 첫 베기 → 두 번째 베기 → 종료

- 원신 여행자의 강공격 모션 참고.
- 강공격 1회에 2회 타격. 두 베기 모두 일반공격보다 넓은 전방 부채꼴 적용.
- 강공격 시작 시 대상 방향으로 보정하고, 짧게 전진하며 두 번 베기.

### 낙하공격 — 공중·접촉·착지 판정

| 구간 | 판정과 범위 |
|---|---|
| 공중 공격 | 공중에서 공격 1회 · 동일 적 최대 1회 |
| 낙하 접촉 | 수직 낙하 중 접촉 피해 · 같은 적도 일정 간격 후 재타격 가능 |
| 착지 공격 | 착지 지점 중심 범위 피해 · 기존 접촉 대상도 별도 1회 적용 |

양양의 낙하 모션을 참고합니다. 수직으로 낙하하며 적을 따라 이동하지 않습니다. 범위와 재타격 간격은 모션·중복 피해를 확인해 조정할 수 있습니다.

### 전투 스킬 — 돌진과 경로 피해

> 시전 준비 → 돌진 중 경로 타격 → 동작 종료

| 항목 | 규칙 |
|---|---|
| 방향 입력 없음 | 가장 가까운 적 우선 |
| 방향키와 스킬 동시 입력 | 입력 방향 우선 |
| 피해 범위 | 돌진 경로에 닿은 적에게 피해 |
| 충전 | 1회 충전 6초 · 패시브 1 적용 시 최대 2회 |
| 재사용 | 시전 후 0.5초 |
| 표식 | 패시브 2 적용 시 추가되는 기능 |

미야비의 강화 특수 스킬을 참고합니다. 돌진으로 이동 편의를 제공하며, 범위·동작 시간은 모션과 전투 테스트에 맞춰 조정할 수 있습니다.

### 필살기 — 준비 자세와 지연 타격

| 구간 | 연출·판정 |
|---|---|
| 준비 | 몸을 낮추고 칼집·손잡이를 잡는 자세 · 벽력일섬의 준비 동작 참고 |
| 발도 | 대상 방향으로 보정한 뒤 제자리에서 베기 |
| 피해 | 베기 후 0.3~0.5초 뒤, 확정 대상에게 1회 피해 |
| 마무리 | 구원 공명해방의 종료 연출 참고 |

**대상 판정과 피해 적용 시점을 구분합니다.** 시전 시작 시 전방 넓은 부채꼴 안의 대상과 표식 중첩을 확정하고 해당 표식을 소모합니다. 이후 대상을 다시 판정하지 않고, 베기 후 지연 시점에 확정 대상에게 피해를 적용합니다.

> 시전 시작: 대상·중첩 확정 및 표식 소모 → 베기 → 0.3~0.5초 → 확정 대상에 1회 피해

제자리 단발 발도로 큰 피해를 주는 구성입니다. 공격 범위와 동작 시간은 모션·전투 테스트에 맞춰 조정할 수 있습니다.

## 05 패시브와 조건부 연계

### 패시브 — 전투 스킬과 필살기의 연결

| 패시브 | 규칙 |
|---|---|
| 패시브 1 · 충전 | 최대 2회 · 1회 충전 6초 · 시전 0.5초 후 재시전 |
| 패시브 2 · 표식 | 전투 스킬 적중 시 표식 부여 · 최대 2중첩 · 4초 유지 · 재적중 시 갱신 |
| 표식 소모 효과 | 중첩당 해당 대상에게 필살기 피해 +20% · 2중첩 시 +40% |

표식 부여는 **패시브 2의 기능**입니다. 필살기 시전 시 중첩을 확정하고 표식을 소모한 뒤, 지연 타격 시 강화 피해를 적용합니다. 피해 증가 수치는 실제 시스템에 맞춰 조정할 수 있습니다.

> 전투스킬 적중 → 표식 중첩 → 필살기로 소모·피해 강화

### 연계 스킬 — 교대와 순간 집결

**온필드 동료의 필살기 적중**이 트리거입니다. 제안 캐릭터는 대기 상태이며, 자신의 연계 쿨타임이 준비되어 있어야 합니다.

| 주체·단계 | 흐름 |
|---|---|
| 동료 · 온필드 | 필살기를 준비하고 원하는 시점에 사용·적중 |
| 제안 캐릭터 · 대기 | 조건 충족 시 QTE 4초 활성화 · 초상화 강조 |
| 플레이어 입력 | 강조된 초상화 또는 교대 키 입력 → 교대·연계 공격 |
| 등장 효과 | 교대 위치의 본인 중심 범위에 흡인·타격 각 1회 동시 적용 |

동료 필살기의 충전이라는 전제로 반복 발동을 제한하면서 사용 시점은 플레이어가 선택합니다. 제안 캐릭터는 적을 추격하지 않으며, 흡인 반경·인력·동작 시간은 테스트에 맞춰 조정할 수 있습니다.

## 06 운용 요약과 제안 결론

### 직접 전투의 역할

| 기본 공격 | 전투 스킬 | 필살기 |
|---|---|---|
| 일반·강·낙하 공격으로 초반 전투 진행 | 돌진 이동과 경로 피해 | 충전 후 큰 단발 피해 |

세 공격은 역할이 다른 공격 수단입니다. 패시브 2 적용 시 전투 스킬의 표식을 필살기로 소모하는 추가 연결이 생깁니다.

### 조건부 교대 흐름

> 동료 필살기 사용·적중 → QTE 활성화 → 강조된 초상화 입력 → 교대·연계 공격 → 전투 이어가기

### 제안 요약

| 역할 | 기대 효과 |
|---|---|
| 초반 진행 지원 | 기본 공격으로 진행하고 돌진·집결로 전투 편의 확보 |
| 기본 전투 규칙 학습 | 이동·점프·공격·스킬, 필살기 충전·사용 등 다른 캐릭터에도 적용할 공통 규칙 습득 |
| 게임 고유 연계 학습 | 조건 충족부터 기회 활성화, 입력·교대까지 이어지는 연계 흐름 습득 |

**기본 전투와 게임 고유의 연계를 익혀, 다른 캐릭터를 활용할 기반을 만드는 초기 캐릭터입니다.**
