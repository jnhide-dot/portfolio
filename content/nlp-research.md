## 한국어 댓글의 혐오 표현을 분류하는 모델을 비교했습니다

자연어 처리 학부연구생으로 참여한 연구입니다. 한국어 혐오 표현 데이터셋 두 종류에 세 가지 언어 모델을 적용하고, 학습 경과와 분류 결과를 비교했습니다.

원 연구 제목은 **「한국어 혐오 발언 댓글 분류를 위한 언어 모델 별 비교」**입니다. 아래 내용은 연구 발표 자료의 실험과 결과를 정리한 것입니다.

## 담당 업무

**데이터 전처리부터 모델 학습, 비교 실험, 결과 분석과 발표 자료 작성까지 담당했습니다.**

| 참여자 | 담당 |
| --- | --- |
| 어식 | 데이터 전처리 · 모델 학습 · 비교 실험 · 결과 분석 · 발표 자료 작성 |
| 배인수 | 발표 |
| 이수안 교수 | 검수 |

## 비교한 대상과 방법

- **데이터:** K-MHaS, UnSmile의 혐오 표현 분류 레이블을 활용했습니다.
- **모델:** BBMC, KoBERT, KcELECTRA를 각각 학습했습니다.
- **학습 경과:** 모델별 Loss와 검증·테스트 정확도를 비교했습니다.
- **분류 결과:** 새로운 입력 문장에 대한 레이블과 확률을 비교해, 수치와 실제 출력 결과를 함께 살펴봤습니다.

## 실험 결과

발표 자료에 기록된 정확도입니다. 소수 값으로 표기했으며, 두 데이터셋의 레이블 구성은 서로 다릅니다.

| 데이터셋 | 모델 | 검증 정확도 | 테스트 정확도 |
| --- | --- | --- | --- |
| K-MHaS | BBMC | 0.7517 | 0.7275 |
| K-MHaS | KoBERT | 0.3725 | 0.3579 |
| K-MHaS | KcELECTRA | **0.8497** | **0.8480** |
| UnSmile | BBMC | 0.6171 | 0.6141 |
| UnSmile | KoBERT | 0.2497 | 0.2466 |
| UnSmile | KcELECTRA | **0.7557** | **0.7434** |

이 실험에서는 KcELECTRA가 두 데이터셋 모두 가장 높은 검증·테스트 정확도를 보였습니다. 전체 정확도와 함께 새 문장의 분류 결과를 확인하며 모델 간 차이를 분석했습니다. 결과는 해당 실험 조건에서의 비교입니다.
